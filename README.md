# guide-index-cn

一个用于归档和发布多个独立 HTML 页面的通用仓库。

## 项目简介

本仓库主要用于收集、整理并托管一系列独立的 HTML 页面。这些页面各自独立，不依赖于任何特定域名或网站，适合作为静态资源进行浏览、测试或参考。

仓库本身不提供任何特定服务或内容索引，仅作为页面存档与展示的载体。

## 目录说明

```
.
├── index.html          # 仓库首页/导航页（如有）
├── pages/              # 存放独立 HTML 页面的目录
│   ├── example1.html
│   ├── example2.html
│   └── ...
├── assets/             # 公共资源文件（CSS、JS、图片等）
│   ├── css/
│   ├── js/
│   └── images/
└── README.md           # 本文件
```

- `pages/`：每个 HTML 文件应保持自包含，可引用 `assets/` 下的公共资源。
- `assets/`：存放页面间共享的样式、脚本或图片等静态资源。

## 页面归档说明

- 所有页面均为独立 HTML 文件，可直接通过浏览器打开或部署至任意静态托管服务。
- 每个页面应尽量保持自包含，避免外部依赖失效导致无法正常展示。
- 页面内容不针对特定域名或网站，不包含任何营销或诱导性信息。

## 维护说明

- 欢迎提交 Pull Request 添加或更新页面。请确保新增页面符合上述独立性要求。
- 提交前请检查页面是否引用未包含在仓库内的外部资源（如外链图片、脚本等），建议将资源一并放入 `assets/` 目录。
- 如有大规模调整，建议先通过 Issue 讨论。
